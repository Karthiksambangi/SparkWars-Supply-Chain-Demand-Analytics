# Spark-Wars 4.0 – Supply Chain Demand Analytics

## Overview
This project implements a scalable supply chain demand analytics pipeline using Databricks and Apache Spark. The solution follows Medallion Architecture.

## Architecture
- Bronze Layer → Raw data ingestion
- Silver Layer → Data cleaning and transformation
- Gold Layer → Business KPI aggregation

## Technologies Used
- Databricks Serverless
- Apache Spark (PySpark)
- Delta Tables

## KPIs Generated
- Total products per period
- Analytical business aggregation

## Execution Steps
1. Import notebook (.dbc)
2. Run notebook top to bottom
3. Gold KPI table will be created
